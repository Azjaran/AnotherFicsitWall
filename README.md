# Another Ficsit Wall

This Mod adds the old Ficsit Wall before it was changed with Update 5, but now with the twist that both sides are the same.

## Features

 - The __Old Ficsit Material__ can be found in the AWESOME Shop like the other wall materials.
 - Supports all vanilla Wall shapes and there materials.
 - Supports coloring/swatches like the vanilla walls.
 - __New:__ Uses the [Customizer Material Framework](https://ficsit.app/mod/CustomizerMaterialFramework). So any other Mod that adds a new Wall Material and uses it, the Customzier Materials are easily interchangeable.
